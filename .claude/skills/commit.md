staged된 변경사항을 확인하고 아래 컨벤션에 맞는 커밋 메시지를 작성한 뒤 커밋하세요.

**형식:** `<type> : <설명>`

**타입:**
- `feat` : 새로운 기능 추가
- `fix` : 버그 수정
- `refactor` : 리팩토링 (기능 변경 없음)
- `docs` : 문서 수정
- `test` : 테스트 코드 추가/수정
- `chore` : 빌드, 설정 등 기타 변경

**규칙:**
- 타입과 설명 사이 ` : ` (공백 포함)
- 설명은 한국어, 명령형으로 간결하게
- staged 없으면 사용자에게 알릴 것
