FE팀에 전달할 API 변경사항을 아래 포맷으로 요약하고 Discord로 전송한다.

$ARGUMENTS 에 변경된 API나 커밋 관련 힌트가 있으면 참고하고, 없으면 최근 git 변경사항에서 API 변경 내용을 파악한다.

**요약 포맷 (반드시 이 형식 그대로 사용):**

```
📋 **[API 변경사항] {제목}**

**엔드포인트**
`{HTTP_METHOD} {경로}`

**변경 내용**
{변경 배경 및 설명을 1~3문장으로}

**{변경 항목 제목 (예: 추가된 쿼리 파라미터 / Request Body 변경 / Response 변경)}**
{변경된 필드나 항목을 bullet로 나열, 신규/제거/수정 여부 명시}

**요청 예시**  ← Request Body나 파라미터가 있을 때만 포함
{예시 코드}

**기존 호환성**  ← 해당될 때만 포함
{하위 호환 여부 설명}
```

엔드포인트가 여러 개면 `---` 구분선으로 나누어 각각 위 포맷을 반복한다.

요약이 완료되면 사용자에게 먼저 보여주고, "Discord로 전송할까요? (YES/NO)" 라고 물어본다. 사용자가 YES라고 하면 /discord skill을 사용해 전송한다. 메시지 전체를 argument로 그대로 전달한다.

전송 후 성공 여부를 사용자에게 알린다.
